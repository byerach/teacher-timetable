# מערכות מורים — בית ירח

אפליקציית GitHub Pages להצגת מערכת אישית לכל מורה ולמציאת שעות פנויות משותפות למספר מורים.

## מה יש באפליקציה
- מסך **מערכת מורה** — בחירת מורה והצגת המערכת השבועית שלו.
- מסך **מציאת זמן משותף** — בחירת כמה מורים והצגת כמה מהם פנויים בכל שעה.
- לחיצה על שעה מציגה מי פנוי ומי מלמד, כולל מקצוע, קבוצה וכיתת לימוד.
- הטקסט שבסוגריים באתר שחף נשמר בשדה `classroom` ומוצג עם 📍.

## פרסום ב-GitHub Pages
1. העלו את כל תוכן התיקייה לריפו חדש.
2. GitHub → Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`, תיקייה `/ (root)`.

## איסוף כל המערכות
בקובץ `data/timetable.json` מצורפים כרגע נתוני הדגמה שנקראו ממערכת ט1.
לאיסוף אוטומטי של כל הכיתות:

```bash
pip install -r requirements.txt
python scrape_shahaf.py
```

הסקריפט עובר על מזהי `cls=1..160`, מאתר מערכות תקינות ושומר את הנתונים ב-`data/timetable.json`.

## רענון אוטומטי ב-GitHub
הקובץ `.github/workflows/update-timetable.yml` מריץ את הסקריפט ב-GitHub Actions בימים א'-ו' ומעדכן את קובץ הנתונים בריפו. ניתן גם להריץ ידנית דרך Actions → Update timetable data → Run workflow.

> חשוב: מבנה ה-HTML של אתר שחף עשוי להשתנות. לכן לאחר ההרצה הראשונה יש לבדוק שמספר הכיתות והמורים שנקלטו הגיוני. אם מבנה האתר שונה, יש לעדכן רק את פונקציית הפענוח ב-`scrape_shahaf.py`; האפליקציה עצמה אינה תלויה במבנה האתר.
